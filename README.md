# Mengo Chamber of Commerce

A premium Next.js frontend concept for the Mengo Chamber of Commerce.

## Getting started
```bash
npm install
npm run dev
```
Visit http://localhost:3000.

## Pages
- / — home
- /about — about and vision
- /membership — membership
- /commercial-centres — commercial centres
- /market-linkages — market linkages
- /business-development — enterprise development
- /investment — investment
- /events — events
- /news — news and insights
- /impact — community impact
- /contact — contact

## Status
Frontend-first design concept. Sample opportunities, statistics, events, businesses and contact details are illustrative placeholders, not verified Chamber data. Forms and member portals require a backend and integrations before launch. Brand and references to Buganda Kingdom require stakeholder approval. No affiliation or endorsement is implied.
